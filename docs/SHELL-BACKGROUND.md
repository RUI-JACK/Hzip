# 右键任务独立运行验证

本页保留无进度窗口版本的历史行为与验证。当前版本已按用户要求加入独立进度窗口、暂停/继续、取消及完成结果页，详见 SHELL-PROGRESS.md。

2026-10-20 更新：右键任务在创建 MainWindow 之前分流处理。除“用 Hzip 打开”之外，右键操作不构造主界面。快捷操作正常完成没有任何窗口；自定义操作只显示设置窗口，确认或取消后自动结束进程。输入密码及错误提示也使用独立窗口。

启动入口支持快捷 ZIP/7Z、新建归档、此处/智能/同名目录/自选目录解压，以及旧版 --extract-here。原生及经典菜单继续使用相同参数，不需要重新注册菜单，也不改变默认关联。

验证脚本 tools/test_shell_background.py 运行真实发布版 Hzip.exe，通过 Windows 窗口显示事件观察各测试进程，并核对实际输出内容、退出码和后台任务状态。覆盖 16 项：快捷 ZIP/7Z、同名保护、四个直接解压参数、自定义创建、自定义解压、多包共用设置、取消两个设置窗口、加密包密码输入、错误密码重试、取消密码和损坏包错误。设置窗口另通过 UI Automation 检查没有主界面导航/列表控件。

tools/test_context_menu.py 在验证器进程中加载交付的原生 DLL 执行动作，另行核对已注册 COM 对象的菜单状态；“用 Hzip 打开”仍会加载归档。该环境不等同于由已注册服务进程启动任务。原有图形编辑/密码库等 6 项工作流程另做回归，使用发布版实际 Hzip.dll。后续通过真实包身份启动和 EFS 环境发现并修复的问题见 EFS-FIX.md。

这轮后台启动更新未修改 Hzip.Core、压缩引擎或菜单 DLL，没有把历史核心检查计为当次重新执行。后续 EFS 修复修改了 Hzip.Core 并重新验证，见 EFS-FIX.md。后台启动修改了 App.xaml.cs、ShellTaskRunner.cs、MainWindow.xaml.cs 与设置/密码窗口的初始化。压缩引擎在子工作进程中运行，后台任务完成或取消后调用显式 Shutdown，不保留隐藏主窗口或常驻 Hzip 进程。

右键后台任务暂不提供进度或暂停窗口；主界面发起任务保留原来的进度、暂停、继续及取消。后台任务状态保存在本机 ShellJobs JSON，不保存密码。异常时保留此前已成功完成的项目，不将整个批次误报成功。

结构化结果由 verification/shell-ui-latest.txt、shell-background-latest.txt 和 menu-0.5-latest.txt 定位。前一轮整体检查见 CURRENT-AUDIT.md；其“应用运行代码不变”仅描述那一轮检查，不代表本次启动逻辑没有修改。
