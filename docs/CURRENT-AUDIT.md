## 仍然存在的限制

- 安全扫描仍不可用，界面中没有该入口；本机 AMSI 初始化返回 0x80070103。测试确认的是明确报告未扫描，不能算作杀毒扫描成功。
- 密码恢复仅有数字范围和候选字典；没有专用高速穷举算法。
- 图片预览依赖系统编解码器，单条预览上限 32 MiB；ZIP 修复无法恢复已经丢失的数据。
- 没有逐一测试所有归档格式变体、其他电脑/架构/DPI、真实 Word/Excel 版本、资源管理器物理鼠标拖放或退出程序后续作。
- 未取得当前 Windows 11 菜单弹出层的可靠像素截图；菜单动作和类型过滤已由实际原生接口及内容结果确认。
