# 解压同名文件判断

2026-10-20，当前 Windows x64 发布版已更新。

## 使用方式

主界面解压、批量解压和所有右键解压默认使用“遇到同名时询问”。没有冲突时直接继续；存在同名内容时，在主窗口或独立进度窗口上方显示处理弹窗，列出目标完整路径，以及新旧内容的字节大小、修改时间。

支持替换、跳过、重命名、全部替换、全部跳过、全部重命名、取消。重命名自动添加 `(2)` 等编号，保留原有内容；替换使用压缩包中的文件。“全部”只应用于当前操作的后续冲突，可以跨本次批量选择的多个归档，不保存为以后操作的默认值。解压设置也保留自动重命名、跳过、覆盖和遇到重名停止等预设策略。

大小和修改时间相同并不代表内容相同，因此仍然询问，且明确显示这条说明。没有根据这两个属性自动覆盖或跳过，也没有把它们当成内容哈希校验。

文件与文件夹发生冲突时，禁用替换，允许跳过或重命名；已有文件夹不会被删除。目录之间正常合并；归档中的文件夹与已有文件冲突时，重命名会同步调整其全部子项位置，跳过则跳过该子树。等待选择期间若目标文件被其他程序修改，会停止替换并提示重新确认。

取消或关闭弹窗会取消当前归档，并回滚本轮已经写入的文件、恢复已替换文件的内容及修改时间；此前已完成的其他归档结果保留。可能保留新建的空目录。若占用导致回滚也失败，沿用原有备份保留和恢复位置提示。右键操作全程使用进度窗口及必要对话框，只有“用 Hzip 打开”创建主界面。

命令行保持原有非交互处理和显式重名策略；不把图形弹窗带入脚本。原有 GZIP 尾部兼容处理、EFS 输出修复及安全路径检查均保留。
