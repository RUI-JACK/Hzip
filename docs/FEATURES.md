# Hzip 0.5 功能对照与验证范围

目标参照是本机 Bandizip 7.46.0.1。官方功能说明用于补全清单，实际实现和测试决定下面的状态；没有用“按钮存在”代替功能完成。Hzip 尚不能称为所有功能和所有边界都完美等价的替代品。

| 能力 | Hzip 当前实现 | 已有证据 / 差异 |
|---|---|---|
| 原生 Windows 桌面界面 | WPF，中文，x64 | 实际窗口启动、200% DPI 截图、940×630 与 1240×810 逻辑尺寸检查 |
| 归档浏览、目录导航、搜索、排序、多选 | 已实现，列表虚拟化 | UI Automation 实际导航和搜索；引擎目录读取上限 64 MiB 输出 |
| 打开嵌套归档 | 解出选定归档到暂存区后在新窗口打开 | 代码实现；大层级、巨大嵌套包没有系统化压力测试 |
| ZIP / ZIP64 创建与解压 | 原生引擎 + ZIP 兼容编解码器 | 中文、空目录、AES 与普通归档；4,294,975,488 字节样本完整回环哈希匹配 |
| 7Z 创建与解压 | LZMA2、固实、等级/线程、密码/文件名加密 | 加密头目录读取、错误密码、回环、分卷已测 |
| ZIPX 创建 | ZIP 方法 95，XZ 内容，UTF-8，含 ZIP64 结构支持 | 普通 ZIPX 已被 Hzip 与 Bandizip 校验；创建时不支持密码/分卷，超 4 GB ZIPX 未实测 |
| EXE 自解压 | 7Z SFX，独立解压模块 | 已创建并用引擎检验/读取/解压；未执行 SFX GUI 进行系统测试 |
| TAR / TAR.GZ / TAR.XZ / TAR.BZ2 | 已实现，自动解开外层 TAR 压缩流 | 创建、测试、内容回环均通过 |
| GZIP / XZ / BZIP2 | 单文件压缩流 | 创建、测试、内容回环通过；多文件用 TAR 系列 |
| ISO | Windows IMAPI2，ISO 9660 / Joliet | 小型中文目录样本创建/读取/解压通过，Bandizip 校验通过；未覆盖启动镜像、UDF、大型光盘边界 |
| LZH | LH0 存储型 LHA | 互操作与回环通过；未实现 Bandizip 的 LH7 压缩，路径编码字节上限 233，单文件小于 4 GB |
| WIM | 7-Zip WIM 创建与读取 | 文件/空目录回环通过；未对 ACL/ADS/系统恢复映像承诺等价 |
| RAR / RAR5 读取 | 7-Zip 解码 | libarchive 的真实 RAR4/RAR5 样本提取后 CRC 匹配；不创建 RAR，与 Bandizip 相同 |
| 其他读取格式 | 随附 7-Zip 26.04 引擎支持的格式 | 可以尝试 CAB、ARJ、DMG 等；未逐格式、逐变体验收，不能称所有输入均兼容 |
| 添加、删除、改名 | ZIP / 7Z / TAR / WIM | 复制到工作副本处理，测试后替换；添加/条目编辑/文件夹改名与删除、失败保留原件已测 |
| 修改归档内文本 | 可预览的文本可编辑并写回 | 真实 GUI 编辑保存、再次解压与内容核对已通过；有未保存修改时提示 |
| 外部编辑后写回 | 系统默认应用编辑持久副本，检测后确认写回 | 受控外部程序原子替换保存、GUI 提示/确认、真实归档内容核对、关闭保留副本已测。原条目冲突、占用、失败和取消保留副本；未逐版本测试 Word/Excel |
| 从列表拖出解压 | 先准备文件/文件夹副本，Windows FileDrop 复制拖放 | 多选、父子重叠、空文件夹、旧编码和源归档保持已测；较大条目需等待准备。物理鼠标拖入 Explorer 未验收；不等于直接向目标解压的快速拖放 |
| 批量解压与智能目录 | 已实现 | 按归档排队；设置智能/同名/原目录，重名策略可选；自动同名目录不是并行性能等价保证 |
| 多线程压缩、任务进度、暂停/继续、取消 | 已实现，保持程序运行 | 原生工作进程暂停期间 CPU 增量为 0；管理代码在检查点暂停；快速切换、暂停中取消、GUI 按钮和恢复后内容哈希已测。不支持退出程序/跨重启断点续作；系统组件及文件提交需等安全边界 |
| 分卷 | ZIP / 7Z，Unicode 密码 ZIP 亦可 | 多卷测试及重新解压；覆盖时事务化替换并回收旧卷，卷数减少与分卷转单卷已纳入测试 |
| 密码与加密 | ZIP AES-256 / ZipCrypto；7Z AES | ASCII、UTF-8、GBK 密码测试；本机编码 ZIP 与 Bandizip 双向通过；旧式工具的密码编码不能假定全球统一 |
| 密码管理 | Windows DPAPI 当前用户保护；创建和打开时可选择已存密码 | 真实 GUI 选择后填充密码及确认，生成归档经正确/错误密码核验；仍缺条目编辑排序、主密码、迁移导入导出 |
| ZIP 修复 | 中央目录/本地头/32 与 64 位描述符交叉恢复，CRC 或加密认证后重建 ZIP，并生成清单 | 已测文件头签名/CRC/大小损坏、SFX 前缀、部分条目坏损、无签名及 ZIP64 描述符、Store/Deflate/BZip2/LZMA、正确密码的 ZipCrypto/AES；错密码和认证失败不输出。结果为未加密 ZIP，数据丢失无法恢复；分卷重组及任意损坏均不作保证 |
| 密码恢复 | 数字范围（1–12 位）及 UTF-8 候选字典 | 用真实加密归档验证；无专用 GPU、ZIP Crypto 大规模加速或自动字符集搜索性能承诺 |
| 图片预览 | Windows WIC 图片解码器，缩放、旋转、帧切换 | PNG 等常规图片可预览；WebP 等取决于系统编解码器，单条内置预览上限 32 MiB |
| 文本预览 | UTF-8、GBK、UTF-16LE BOM 识别 | 编辑上限 4 MiB，普通预览总上限 32 MiB；不是所有文本编码完整探测器 |
| 安全扫描 | 图形界面已移除；仅保留依赖 Windows AMSI 的命令行接口 | 当前机器初始化失败 0x80070103，扫描未执行；未作为可用界面功能展示 |
| SHA-256 | 流式计算 | 小文件与大文件核对均使用此能力 |
| 右键菜单与打开方式 | 经典菜单及原生 Windows 11 IExplorerCommand/MSIX 扩展；默认应用由用户选择 | 新版菜单按普通内容/压缩包切换四项/五项；ZIP/7Z 快捷创建、同名保护、此处/智能/同名/自选目录解压和打开已实测。COM surrogate 的实际安装版本过滤已核对。开发证书的安装/清理需管理员确认；移除后重新注册、证书清理与默认关联保持不变均已测 |
| 文件名编码 | 默认引擎或手动 GBK / Shift-JIS / Big5 / OEM / UTF-8 | 贯通预览、嵌套提取、修改、拖出及批量/右键智能解压。旧 Shift-JIS 包的真实 GUI 预览/写回和核心回环已测；没有新的自动语言识别器 |
| 路径、链接与原件保护 | 检查路径穿越、设备/流路径、重解析点；暂存与替换 | 相关攻击样本及取消覆盖回滚通过；默认不提取符号链接/硬链接，也不完整保留 NTFS ACL/ADS 元数据 |
| 国际化与部署 | 中文 Windows x64，自带运行环境便携包 | 未提供 Bandizip 的完整多语言、本地化、x86/ARM64 和安装器产品线 |

## 尚未达到等价的重点

解压同名判断已实现：主界面与右键默认询问，比较大小/修改时间，支持逐个和全部替换/跳过/自动重命名、取消；文件夹冲突保护及范围见 EXTRACTION-CONFLICTS.md。

GZIP 解压和测试现逐成员验证 CRC/长度；有效流后的外部附加数据作为提示，未写入解压文件，原包保持不变。OpenWrt 用户样本和损坏拒绝等验证见 GZIP-TAIL.md。

右键任务使用独立进度窗口，支持暂停、继续和取消，完成后保留 100% 结果；新建压缩包和自选解压先显示设置，再进入进度窗口。全程不打开主界面，详见 SHELL-PROGRESS.md。SHELL-BACKGROUND.md 保留此前无进度窗口版本的历史验证。

完整多语言、LZH LH7 编码、加密 ZIPX、专用密码恢复加速、退出程序后/跨重启断点续作、所有归档变体与特殊元数据保留尚未完成等价实现。ZIP 恢复、杀毒扫描和图片预览还存在上表列出的明确范围。Windows 11 菜单采用本地开发签名，尚不是面向公众发布的受信任商业签名/商店安装版本。此版本可作为常见归档工作流的可用程序进行验收，不应直接据此卸载唯一的原工具并假定所有历史归档均已验证。

0.2 增补的验证覆盖：独立 Python ZIP 的 Store/Deflate/BZip2/LZMA 和 OEM 437 文件名；独立 PyZipper AES ZIP 的中文密码和 BZip2/LZMA；ZIP/7Z/TAR/WIM 修改后未编辑条目的哈希；输出覆盖源文件、自覆盖解压、重名改名、损坏原件、写入被占用及回滚被阻止时的备份保留。仍不承诺所有归档、存储设备故障或进程突然终止场景都已经验证。
