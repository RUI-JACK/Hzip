# Hzip 0.4 日常操作补全

## 文件名编码

“更多 → 更改文件名编码”选定的编码会贯通当前归档的预览、嵌套归档提取、拖出解压、添加/删除/改名和写回。批量解压与右键启动的智能解压使用当前窗口或设置中的默认编码。命令行修改操作同样接受 `--encoding`。这不等于新的自动编码识别器。

## 拖出解压

在文件列表中选中一个或多个文件/文件夹，按住鼠标左键拖向桌面或资源管理器。Hzip 会先把所选内容准备为实际文件，再开始 Windows 文件复制拖放；较大内容需要按住鼠标等待准备完成。提前松手或取消会保留原归档。拖放只允许复制，不从压缩包删除内容。选中文件夹时包含其中内容和空文件夹，父子同时选中不会重复导出。

这是常规暂存拖出，没有直接向目标目录解压的“快速拖放”。交给 Shell 的缓存保留在 `%LOCALAPPDATA%\Hzip\DragExports`，以兼容目标应用延迟复制；下次启动会清理超过七天的 Hzip 标记缓存。取消发生在准备阶段时立即回收暂存内容。可在确认复制完成并关闭 Hzip 后手动清理该专用缓存目录。

## 创建时使用密码库

密码库有条目时，“创建归档”显示“使用已保存的密码”。选择名称后会同时填写密码与确认密码，仍可手动修改。这里只显示名称，不显示密码明文；密码继续由当前 Windows 账户的 DPAPI 保护。支持加密的创建格式仍是 ZIP、7Z 和 7Z 自解压，选择其他格式不会凭空增加加密支持。

## 外部编辑后写回

1. 打开包内文件的预览，点击“用默认应用打开”。
2. 在外部应用中编辑，保存并关闭文件，再回到 Hzip。
3. Hzip 检测修改后显示提示，点击“确认写回归档”。只有确认后才更新原压缩包。

外部编辑期间内置文本编辑只读，以免两份编辑互相覆盖。写回适用于当前支持修改的 ZIP、7Z、TAR、WIM；其他归档只支持编辑副本，不显示写回按钮。普通预览仍有 32 MiB 上限。

工作副本和不含密码的来源记录保留在 `%LOCALAPPDATA%\Hzip\ExternalEdits`。预览窗口显示具体路径，也可点“打开编辑副本文件夹”。关闭预览或 Hzip 不会删除外部工作副本；文件保存失败、外部应用占用、或压缩包中同一条目已被其他人修改时，写回停止并保留副本。其他条目的变化可以保留并合并，原条目的变化需要手动核对。

写回先拍摄稳定内容副本，再经原有归档副本修改/测试/提交流程处理。外部编辑器在写回期间产生的下一版修改仍会被标记为待写回。关闭时可选择写回、保留副本后关闭或取消。请在外部编辑器中先保存；Hzip 无法检测尚未写入磁盘的编辑器缓冲区，也不保证所有 Word/Excel 版本的文件占用模式一致。

Hzip 不会自动清理外部编辑副本，以免删除未合并内容。它们可能包含原加密归档的明文，请在确认保存后自行整理。

## 验证范围

已验证旧式 Shift-JIS 文件名的预览和修改、多选文件夹导出、空文件夹与重叠选择、密码库选择后真实加密创建、外部原子替换保存检测、确认写回、关闭保留、占用/冲突/取消时保留副本、稳定快照和下一版修改检测。

图形流程使用独立受控编辑程序验证系统默认应用启动，不依赖特定 Office 版本。真实 Word/Excel 和资源管理器的物理鼠标拖放仍需另行验收；文件导出与 Windows FileDrop 数据对象验证不能冒充完整资源管理器鼠标测试。

实现参考：[WPF 拖放](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/drag-and-drop)、[Windows 数据对象](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/data-and-data-objects)。
