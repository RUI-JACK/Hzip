# Windows 11 新版右键菜单

在 Hzip 的“设置与集成”中选择“启用 Windows 11 新菜单”。新版右键菜单按当前选择切换两套内容，不需要进入“显示更多选项”。

普通文件或文件夹，例如 `Clash Verge`，显示：

1. 压缩为“Clash Verge.zip”
2. 压缩为“Clash Verge.7z”
3. 新建压缩包 (Hzip)…
4. 用 Hzip 打开…

识别为压缩包，例如 `Clash Verge (2).7z`，显示：

1. 解压到此处
2. 智能解压到此处
3. 解压到 Clash Verge (2)\
4. 解压到其他文件夹…
5. 用 Hzip 打开…

选中压缩包时隐藏压缩项，选中普通文件/文件夹时隐藏解压项。名字以 `.zip` 结尾的实际文件夹仍作为文件夹处理。按受支持的扩展名识别 ZIP、7Z、RAR、TAR 等；菜单构造时不读取、解压或扫描整个归档。

快捷 ZIP/7Z 直接在源文件旁创建归档；已存在时添加 `(2)` 等序号，不覆盖原件。单文件去掉最后一段扩展名，目录保留完整名称；多选普通内容使用所在目录名。快捷压缩默认不加密，要设置密码、分卷等请选“新建压缩包”。

“解压到此处”保留包内目录结构，直接写入压缩包所在目录；“智能解压”在必要时增加同名目录，避免多个顶层条目散落；“解压到同名目录”始终增加一层归档同名目录。“解压到其他文件夹”对单包打开完整解压设置窗口，多包则选择共同目标并按各自名字分别建目录。已有同名文件默认显示新旧大小和修改时间，询问替换、跳过或重命名，支持对本次后续冲突全部应用及取消；详见 EXTRACTION-CONFLICTS.md。

多选全部为压缩包时提供四个解压入口，多选普通内容或混合选择时提供压缩入口；多选不显示单文件打开项。对文件夹使用“用 Hzip 打开”会从该目录打开选择归档窗口，不把普通文件夹误当成归档读取。

## 右键任务窗口行为

- 快捷 ZIP/7Z、此处解压、智能解压和同名目录解压：只显示独立进度窗口，不打开主界面或归档。完成后保留 100% 结果，点击关闭后退出。
- 新建压缩包：先显示创建设置窗口；确认后进入独立进度窗口，取消设置不会启动任务。
- 解压到其他文件夹：先显示解压设置窗口；多选归档共用一次设置，默认各自创建同名目录。确认后进入独立进度窗口。“完成后打开目标文件夹”默认关闭，可以自行勾选。
- 加密包在进度窗口上询问密码，输错可以重试。失败和取消在结果中明确显示；缺少输入等启动错误使用独立错误提示，不弹出主界面。
- 只有“用 Hzip 打开”会创建并显示 Hzip 主界面。

右键任务使用相同的压缩引擎、路径保护和同名处理，不会静默覆盖已有归档或文件。任务状态记录在 Hzip 数据目录的 ShellJobs 中，不记录密码。进度窗口支持暂停/继续和取消，文件提交等步骤会等待安全边界。取消按钮保留结果页；运行中关闭窗口会先取消，待安全退出后关闭。新建/解压设置取消不会继续执行任务。

这次更新只替换应用的启动路由，菜单 DLL 和已安装身份包不变，本机无需重新安装菜单。

此本地交付使用开发证书签名的 sparse MSIX 身份包。启用程序仅将随附菜单证书加入 LocalMachine/TrustedPeople，并为当前账户注册 Hzip.ContextMenu；不修改默认应用或关闭系统签名检查。私钥留在构建机器的当前用户证书库，未分发。该方案用于本地交付验证，公开发布时应使用正式的受信任签名。

“移除 Windows 11 新菜单”会移除本应用包，并清理本次安装添加的证书信任；经典菜单可单独保留或移除。移动程序后应重新启用菜单来更新外部安装目录。已有资源管理器窗口没有刷新时，关闭该窗口后重新打开。

组件：src/Hzip.Shell/Hzip.Shell.cpp 实现原生 IExplorerCommand；AppxManifest.xml 声明 COM surrogate 和菜单；manage_menu.ps1 管理注册；tools/build_shell.ps1 编译、打包和签名。Explorer 的菜单构造路径不加载 .NET、不进行压缩，也不上传选中的文件。

0.5 使用版本化 DLL `Hzip.Shell.v05r2.dll` 与菜单身份包 0.5.1.0，避免覆盖仍被系统加载的旧 DLL。已信任同一开发证书的本机更新不新增证书；安装脚本让 Windows 原子升级，失败时保留旧菜单，不先卸载工作中的组件。首次在其他机器启用仍可能需要信任证书的管理员确认。

本机验证记录见 verification/menu-0.5 系列与 VERIFICATION.md；历史 0.2 的三个命令记录不代表当前菜单结构。经典菜单保留单独注册的兼容入口；上述动态分组和文件名显示针对 Windows 11 新版 Hzip 子菜单。

历史锁屏截图及不包含弹出层的 PrintWindow 图像不作为菜单外观证据。菜单文字、可见性和原生命令实际运行结果分别记录，不将 COM 激活等同于完整视觉验收。

官方实现依据：[IExplorerCommand 与应用身份](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer)、[带外部安装位置的身份包](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/grant-identity-to-nonpackaged-apps)。
