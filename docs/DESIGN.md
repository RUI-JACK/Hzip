# Hzip 产品与实现约定

Hzip 是可独立运行的 Windows 原生压缩文件管理器。应用名固定为 Hzip。界面默认中文，浅色工作区配深色侧栏，强调归档路径、文件列表、常用操作与可取消的任务进度。压缩文件管理器保持桌面工具的密度，不使用网站式营销首页。

技术：.NET 8 / WPF，核心逻辑独立类库，命令行入口 hz.exe。使用可替换的官方 7-Zip 引擎，附带许可证、来源和对应源码；Hzip 自身代码与 UI 单独实现。引擎调用使用 ArgumentList，不拼 shell 命令。预览、密码库、ZIP 数据恢复、任务队列及集成由 Hzip 实现。

必须可运行：浏览归档、层级导航/搜索、压缩、解压/选取解压、批处理、密码与 AES、分卷/SFX、追加/删除/改名、完整性检查、文本/图片预览、哈希、密码管理、ZIP 恢复、密码候选恢复、用户级右键集成、命令行与便携发布。

界面只展示已有可用实现的功能入口；未实现或已知本机不可用的功能不放置按钮。0.3.1 已移除安全扫描的图形入口。

修改归档先写同目录副本，成功后原子替换；失败/取消保留原件。解压先检查条目路径和链接，使用独立暂存目录；拒绝越界、设备路径及重解析点。合并输出时遵循覆盖策略。取消或错误要回收进程和暂存文件。原始源文件默认保留。

发布前：核心集成测试覆盖真实归档回环、加密与错误密码、中文路径、分卷、修改事务、损坏 ZIP 恢复、取消及路径穿越；实际启动 WPF 并检查截图、窗口缩放和关键操作。兼容性表列出格式与特殊能力的真实状态，未实现或未验证的能力不能标为等价。
