# 右键压缩与解压进度窗口

2026-10-20 更新：右键压缩和解压显示独立任务窗口，包含当前归档/阶段、当前阶段进度、总进度、耗时和结果。完成后保留 100% 结果，点击关闭后退出，不弹出软件主界面。新建归档及自选解压先显示设置窗口，确认后显示进度。

总进度按批次中的归档数量组合当前任务进度；当前阶段百分比来自引擎或写入阶段。引擎各阶段会重新计数，因此总进度保持单调，并在最终提交成功后才标记 100%，不会把引擎暂存区处理完成当作整个任务完成。耗时为实际经过时间，没有展示未经计算的剩余时间或速度。

暂停/继续使用已有 JobControl 和原生工作进程暂停机制。文件提交等步骤等待安全边界；暂停成功后停止不确定进度条动画。取消后停止工作进程并等待清理/回滚，显示取消结果；直接关闭运行中的窗口也会先安全取消。失败不会被标为 100% 成功。已完成的前序归档保留并在结果中说明。

支持在完成页主动打开目标文件夹。密码询问是进度窗口的子对话框，取消密码后任务显示已取消；不启动主界面。此前的 EFS 内容流提交修复保留。

## 验证

tools/test_shell_progress.py 覆盖 16 项真实发布程序流程：快捷 ZIP/7Z、三种直接解压、多包总进度、自定义创建/解压、设置取消、错误结果、加密包及取消密码、暂停/恢复后内容哈希、暂停中取消、关闭窗口取消。检查实际进度条值、终态结果、输出内容和进程退出，不以按钮存在当作功能完成。

96 MiB 随机数据的实际压缩任务暂停 600 毫秒期间，原生工作进程 CPU 时间增量为 0；继续后完整压缩/解压哈希一致。取消不会留下最终归档。另由 tools/test_packaged_progress.py 从实际注册的 COM 服务启动 256 MiB 任务，检查暂停、恢复、实际输出及进度完成，不只在验证器中加载 DLL。

tools/test_packaged_efs.py 在真实包身份及 EFS 临时目录下继续验证 4 项压缩/解压，并检查完成窗口及关闭；原有 6 项图形工作流程另做回归。本次未修改压缩核心、EFS 提交代码和菜单 DLL，历史核心检查不计为本次重新执行。

结果由 verification/shell-progress-latest.txt 和 shell-progress-ui-latest.txt 定位。截图来自运行中的发布程序，包含实际暂停、取消、失败及完成页。
